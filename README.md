# 🐵 PAINTBALL FPS 

페인트탄을 쏴서 상대를 맞추고, 맞은 부위에 리얼하게 페인트가 칠해지는 1인칭 멀티플레이 슈팅 게임입니다.  
복잡한 생각 없이 쏘고 달리는 **무한 부활 개인전(FFA) 데스매치**를 지향하며 1인 개발 프로젝트로 진행 중입니다!

---

## 🎮 게임의 핵심 재미 요소
- **피 대신 페인트** : 피격 위치에 DecalProjector 기반 페인트가 뼈(bone)에 부착되어, 캐릭터가 움직여도 맞은 부위에 페인트가 따라다닙니다.
- **투명 원숭이** : 캐릭터는 기본적으로 투명합니다. 페인트를 맞아야만 실루엣이 드러나고, 사망하는 순간 투명화가 풀리며 정체가 까발려집니다!
- **이동 페인트 트레일** : 걷거나 뛸 때마다 바닥에 자기 색상 페인트가 찍혀 이동 경로가 노출됩니다. 투명해도 흔적은 남습니다!
- **발자국 스텔스 시스템**: 상대가 바닥에 흘려둔 페인트를 밟으면 당신의 발밑에 '형광 발자국'이 남습니다! 칠할수록 유리하지만, 반대로 너무 많이 칠해두면 조용히 암살하러 가는 길이 막히는 양날의 검입니다.
- **2층 구조 실내 아레나**: 40×40m 밀폐된 창고형 공간에 미로 벽, 나무 상자, 드럼통, 바리케이드가 대칭 배치된 밸런스 맵에서 치열한 전투가 벌어집니다.
- **제한 시간 내 최다 킬 승리**: 한 판에 2~4인이 참여해, 정해진 시간 안에 제일 많이 쏜 사람이 이기는 근본 데스매치 룰입니다.
- **11색 페인트 색상 선택**: 로비에서 자기만의 색을 골라 총기 스킨과 페인트 색이 바뀝니다. 같은 색은 중복 불가!

## ✅ 지금까지 완성된 기능들

### 1. 캐릭터 이동 및 물리 처리
- 1인칭 시점 (마우스 회전, 상하 각도 제한)
- `CharacterController` 기반 이동, 달리기, 점프
- 5초간 일정 거리(1m) 이상 안 움직이면 바닥에 강제 데칼 생기는 '정지 패널티' (제자리 점프 꼼수 차단)

### 2. 사격 및 전투 시스템
- 포물선을 그리는 Rigidbody 기반 페인트탄
- 초당 3발 연사, 15발 탄창 + 재장전 시스템 (R키)
- 자기 위치에서 쏜 총알에 자해하지 않도록 물리 충돌 무시 로직 적용
- 오브젝트 풀링 (총알 100개, 데칼 150개, 발자국 80개) 적용으로 프레임 드랍 원천 봉쇄

### 3. 정밀 타격 시스템 (뼈 기반 11-파트 히트박스)
- 기존 T-포즈 고정 히트박스 → **골격(뼈) 트랜스폼에 직접 콜라이더 부착** 방식으로 전환
- 애니메이션에 100% 연동: 달리기, 점프, 사망 모션에서도 정확한 피격 판정
- 머리(SphereCollider), 상체/골반/양팔 상·하/양다리 상·하(CapsuleCollider) 총 11파트
- 부위별 데미지 다중 적용 (헤드샷 20딜, 그 외 10딜)
- 레이어(`Hitbox`) + 태그(`Head`/`Body`)로 물리·판정 완전 분리

### 4. 리얼 페인트 칠하기 (DecalProjector + UV 병행)
- 총알 충돌 시 **DecalProjector 데칼**을 히트 본(bone)의 자식으로 부착 → 벽/바닥과 동일한 비주얼
- 캐릭터 이동 시 데칼이 뼈와 함께 따라다님 (부모-자식 관계)
- UV 텍스처 페인팅도 병행 유지 (사망 시 `_RevealAmount` 노출 연출에 활용)
- SkinnedMeshRenderer 대응 (BakeMesh로 동적 UV 좌표 추출)

### 5. 사망/리스폰 시스템 (3인칭 데스캠)
- 사망 시 조작 완전 잠금 → 3인칭 숄더뷰 데스캠 전환 (SphereCast 벽 보정)
- 투명화 완전 해제 연출: 사망하는 순간 `_RevealAmount=1`로 전신이 드러남 (정체 까발림!)
- 3초 후 랜덤 스폰포인트 부활: HP/페인트/애니메이션/투명화 모두 클린 리셋
- `CharacterController` 텔레포트 물리 버그 방지 (enabled 토글)

### 6. 페인트 트레일 & 발자국 스텔스 시스템
- **이동 페인트 트레일**: 0.8m마다 바닥에 팀 색상 데칼이 자동 생성 (점프 중 미생성)
- **발자국 감지**: 타인의 페인트를 밟으면 자신의 팀 컬러 발자국 생성 (CheckSphere + PaintTrigger 레이어)
- **발자국 최적화**: 0.6m 간격 감지, 이동 방향 회전 적용, 4초 후 자동 소멸
- 렌더링/물리 레이어 완전 분리 설계 (자식 오브젝트로 Trigger 콜라이더 격리)

### 7. URP DecalProjector 기반 페인트 데칼
- **URP DecalProjector**로 전환: 바닥·벽·모서리·곡면에도 자연스럽게 투영되는 데칼
- **팀 컬러 사전 생성 머티리얼**: `DecalTintCache`가 팀별 사전 제작 머티리얼(Red/Blue)을 캐시 로드
- Decal 셰이더 그래프 + DecalRendererFeature(ScreenSpace) 구성
- 기존 MeshRenderer + MaterialPropertyBlock 방식 완전 폐기 (DecalProjector는 Renderer가 아니므로 MPB 무시됨)

### 8. 킬 피드 & 점수 시스템
- 킬 발생 시 우상단 킬 피드 자동 표시 (`Player >> DummyEnemy [HEADSHOT]`)
- 4초 후 자동 소멸, 최대 5개까지 스택
- Tab 키로 실시간 점수판 토글 (킬/데스 기준 순위 정렬)
- **플레이어 색상 표시**: 스코어보드에 각 플레이어의 페인트 색상(■)이 이름 옆에 표시
  - Photon CustomProperties(`"tc"` RGBA → `"pc"` 팔레트 인덱스) 우선순위 기반 색상 추출
- ScoreManager 싱글톤으로 킬/데스 데이터 중앙 관리

### 9. 게임 매니저 (라운드 시스템)
- 상태 머신: 대기(Waiting) → 카운트다운(3초) → 플레이(3분) → 게임 오버
- **PhotonNetwork.Time 기반 서버 시간 동기화** — 모든 클라이언트가 동일한 남은 시간 표시
- 라운드 타이머 HUD 표시 (30초 이하 빨간색 경고)
- 게임 오버 시 1등 표시 + 점수판 자동 오픈
- 멀티플레이 GameOver → 자동 로비 복귀, 연습 모드 → 자동 재시작
- SyncToCurrentState 패턴으로 Start() 실행 순서 무관하게 안전 동기화
### 10. 사격 이펙트 & 사운드
- SFXManager: AudioSource 풀링(10개) 기반 3D 사운드 재생 시스템
- 발사음, 피격음, 헤드샷음, 재장전음 전부 구현
- 재장전 2.5초 딜레이 + HUD "RELOADING..." 표시
- **BGM 시스템**: 카운트다운 시작 시 재생, 게임 오버 시 2초 페이드아웃, 로비 복귀 시 즉시 정지
- **킬 알림 사운드**: 킬/헤드샷 달성 시 로컬 2D 효과음 즉시 재생 (ScoreManager.OnKillEvent 구독)

### 11. 아레나 맵 (ProBuilder)
- 40×40m 실내 창고형 2층 구조 아레나
- 외벽 4면 (6m) + 천장, 미로형 내부 벽 16개
- 2층 플랫폼 4개 (도넛형 연결) + 기둥 8개 + 계단 2개 + 난간
- 엄폐물: 나무 상자(18), 드럼통(12), 콘크리트 바리케이드(12) 대칭 배치
- 포인트 라이트 9개 (따뜻한 백색) + 주황 경고 스트라이프 장식
- 10개 스폰 포인트 (1층 8곳 + 2층 2곳)

### 12. 맵 최적화
- Static 플래그 일괄 설정 (Arena 119개 오브젝트)
- Mixed Lighting + GPU 라이트맵 베이크 (1024×1024 × 4장)
- Occlusion Culling 베이크 (미로형 맵 특화)

### 13. Photon PUN 2 로비 시스템 (방 브라우저 + 준비 시스템)
- **Main Panel**: 닉네임 입력 → 방 만들기 / 방 목록 참가 / 연습 모드 선택
- **CreateRoom Panel**: 방 제목 입력 + 최대 인원 버튼 셀렉터(◀ 2~4명 ▶)
- **Room Panel**: 플레이어 목록 + Ready 상태 표시 + 방장 시작 버튼
- **로비 슬롯 동적 제어**: 최대 인원 설정에 따라 불필요한 슬롯 자동 숨김
- **방장 시작 방식**: 전원 준비 완료 + 최소 2명 충족 시 방장이 게임 시작
- **연습 모드**: `PhotonNetwork.OfflineMode`로 혼자서 즉시 게임 진입
- **실시간 방 목록**: Photon 로비에서 delta 업데이트로 자동 갱신
- Custom Properties(`isReady`, `startTime`, `roomName`)로 상태 동기화

### 14. 멀티플레이어 네트워크 동기화
- PlayerController/PlayerShooter: `photonView.IsMine`으로 로컬/원격 플레이어 완전 분리
- **원격 플레이어 레이어 전환**: `LocalPlayer` → `Default` 레이어 자동 변경 (카메라 cullingMask 가시성 보장)
- MonkeyHealth: `TakeDamageNetwork()` RPC → 피격자 Owner에게만 데미지 전달 (HP 일관성 보장)
- **사망/리스폰 RPC 안정화**: `animator.Play()` 직접 전환 (Trigger 타이밍 불안정 해결)
- `SetReveal()` 방어 코드: `MaterialPropertyBlock` null 안전 초기화 + fallback 렌더러 처리
- ScoreManager: `RecordKillNetwork()` RPC → 전 클라이언트 킬피드 브로드캐스트
- PaintProjectile: 로컬 생성/파괴, 충돌 시 데미지만 RPC 전달 (FPS 표준 아키텍처)
- NetworkManager: 스폰 후 닉네임/HUD/ScoreManager 자동 등록 + OfflineMode 호환
- `AutomaticallySyncScene` + `PhotonNetwork.LoadLevel`로 전원 동시 씬 전환
- **11색 페인트 색상 동기화**: Photon Custom Properties(`"pc"`) 기반, 로비 선택 즉시 전파
- **원격 플레이어 이름 동기화**: PhotonView.Owner.NickName으로 스코어보드/킬피드 이름 보장
- **카운트다운 입력 차단 강화**: GameManager 상태를 PlayerController에서 매 프레임 직접 체크

### 15. 1인칭 건 모델 & 커스터마이징
- Paintball_Maker 에셋을 Main Camera 하위에 배치 (로컬 플레이어 전용)
- 발사 반동 kickback (뒤로 밀렸다 부드럽게 복귀)
- 재장전 시 아래로 기울어지는 연출
- 로비에서 선택한 색상(11색)에 따라 MarkerBody 스킨 자동 전환 (1:1 직접 매핑)
- 사망 시 건 숨김, 부활 시 복원
- 원격 플레이어 건 비표시 (투명 캐릭터 스텔스 메카닉 보존)
- **로비 총기 커스터마이징 UI**: 총구(20종)/그립(18종)/플래시라이트(9종+없음) ◀▶ 스위처
- **3D 프리뷰**: RenderTexture + 전용 카메라로 실시간 미리보기
- **저장**: PlayerPrefs(영구) + Photon Custom Properties(세션별 플레이어 독립)

### 16. 피격 화면 이펙트
- 피격 시 화면 가장자리에 공격자의 페인트 색상으로 비네트 효과 표시
- 사망 시 화면 전체를 빨간색으로 채우는 전체화면 이펙트
- 부활 시 이펙트 자동 초기화 (죽었다 살아나도 화면이 깨끗)
- RawImage + 커스텀 비네트 텍스처(`HitVignette.png`) 기반 구현

### 17. 11색 페인트 색상 선택 시스템
- 로비 RoomPanel에서 11색 팔레트 중 자기 색상 선택 (검정/파랑/초록/연두/네이비/주황/핑크/보라/빨강/하양/골드)
- **중복 선택 차단**: 다른 플레이어가 고른 색은 🔒 잠금 + 닉네임 표시
- **실시간 동기화**: Photon `OnPlayerPropertiesUpdate` 콜백으로 즉시 반영
- **PlayerPrefs 영구 저장**: 다음 세션에서도 마지막 선택 색상 자동 복원
- 선택한 색상은 총기 스킨 + 페인트탄 + 트레일 + 발자국에 모두 적용

### 18. 크로스헤어 커스터마이징 시스템
- **로비 설정 UI**: 설정 탭에서 크로스헤어의 모든 요소를 실시간 프리뷰와 함께 조정
- **슬라이더 6종**: 선 길이(1~20) / 선 두께(1~6) / 중심 간격(0~20) / 점 크기(1~6) / 외곽선 두께(1~3) / 사격·이동 확장량(1~15)
- **토글 7종**: 조준선 표시 / 십자선(4개 선) 표시 / 중심 점 / 외곽선 / T자 모양(윗선 제거) / 사격 시 벌어짐 / 이동 시 벌어짐
- **9색 프리셋**: 초록·빨강·파랑·노랑·핑크·하양·시안·주황·검정 원클릭 색상 변경
- **초기화 버튼**: 모든 설정을 기본값으로 즉시 리셋
- **동적 확장**: 사격 시 고정값 확장 + 이동 시 수평 속도 기반 실시간 확장 (Lerp 복귀)
- **연사 폭주 방지**: `dynamicAmount × 3` 클램프로 크로스헤어 화면 이탈 차단
- **영구 저장**: PlayerPrefs(JSON 직렬화)로 세션 간 설정 유지
- **인게임 자동 적용**: 게임 시작 시 저장된 설정 자동 로드 + 사망/부활 시 리셋

### 19. 페인트 수류탄 시스템 (블루존 스타일)
- **G키 투척**: 카메라 전방 + 포물선으로 TAGinn R2Bm EVO 수류탄 투척
- **블루존 폭발**: 2초 타이머 기폭 → 반투명 팀색 구체가 **천천히 확장** (SmoothStep)
  - 반경 4m, 4초 유지 후 수축 소멸 (투명도 + 크기 동시 페이드)
- **존 데미지**: 범위 내 적에게 0.5초 간격 DPS (자폭 없음, 투척자 제외)
- **바닥 데칼**: 존 영역에 팀색 데칼 5~8개 랜덤 산포
- **Photon 동기화**: `PhotonNetwork.Instantiate` + `RPC_Explode`로 전 클라이언트 일괄 생성
- **부활 시 보충**: 죽으면 설정된 수류탄 수로 자동 리필
- **HUD**: 잔여 수류탄 개수 표시 (0개면 아이콘 숨김)

### 20. 호스트 방 설정 시스템 (GameSettings)
- **방장 전용 설정 패널**: RoomPanel 내 ⚙ 버튼 → 9개 설정 조절 (◀ 값 ▶ 방식)
- **설정 항목 9개**:
  | 설정 | 기본값 | 범위 |
  |---|---|---|
  | 라운드 시간 | 180초 | 60~600 |
  | 최대 체력 | 100 | 50~300 |
  | 탄창 크기 | 15발 | 5~50 |
  | 헤드샷 데미지 | 20 | 5~100 |
  | 바디샷 데미지 | 10 | 5~50 |
  | 패널티 시간 | 5초 | 3~15 |
  | 패널티 데미지 | 5 | 1~20 |
  | 수류탄 개수 | 1개 | 0~5 |
  | 수류탄 존 DPS | 10 | 5~30 |
- **Photon Room CustomProperties** 기반 직렬화 — 게임 시작 시 `LoadFromRoom()`으로 전원 동기화
- **적용 대상**: GameManager(라운드), MonkeyHealth(체력), PlayerShooter(무기/수류탄), PlayerController(패널티)
- **비호스트에겐 버튼 자체 숨김** (MasterClient 여부로 가시성 제어)
