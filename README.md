# 🐵 PAINTBALL FPS 

페인트탄을 쏴서 상대를 맞추고, 맞은 부위에 리얼하게 페인트가 칠해지는 1인칭 멀티플레이 슈팅 게임입니다.  
복잡한 생각 없이 쏘고 달리는 **무한 부활 개인전(FFA) 데스매치**를 지향하며 1인 개발 프로젝트로 진행 중입니다!

---

## 🎮 게임의 핵심 재미 요소
- **피 대신 페인트** : 피격 위치를 정확하게 계산해 텍스처(UV)에 물감이 번지는 스탬프 기능을 구현했습니다.
- **발자국 스텔스 시스템 (예정)**: 상대가 바닥에 흘려둔 페인트를 밟으면 당신의 발밑에 '형광 발자국'이 남습니다! 칠할수록 유리하지만, 반대로 너무 많이 칠해두면 조용히 암살하러 가는 길이 막히는 양날의 검입니다.
- **무조건 1층, 무조건 돌격**: 계단과 2층 구조를 완전히 배제한 1층 평면 '미로 & 엄폐물' 구조에서 치열한 포물선 전투가 벌어집니다.
- **제한 시간 내 최다 킬 승리**: 한 판에 2~4인이 참여해, 정해진 시간 안에 제일 많이 쏜 사람이 이기는 근본 데스매치 룰입니다.

---

## 🛠 시스템 & 개발 환경
- **엔진:** Unity 6.3.11f1 (URP)
- **네트워크:** Photon PUN 2 (연동 예정)
- **기본 무기:** 연사형 페인트 건 (무기 교체 ✕, 단일 무기 시스템)

---

## ✅ 지금까지 완성된 기능들 (뼈대 완성)

1. **캐릭터 이동 및 물리 처리**
   - 1인칭 시점 (마우스 회전, 상하 각도 제한)
   - `CharacterController` 기반 이동, 달리기, 점프
   - 5초간 일정 거리(1m) 이상 안 움직이면 바닥에 강제 데칼 생기는 '정지 패널티' (제자리 점프 꼼수 차단)
2. **사격 및 전투 시스템**
   - 포물선을 그리는 Rigidbody 기반 페인트탄
   - 초당 3발 연사, 15발 탄창 + 재장전 시스템 (R키)
   - 자기 위치에서 쏜 총알에 자해하지 않도록 물리 충돌 무시 로직 적용
   - 오브젝트 풀링 (총알 100개, 데칼 150개) 적용으로 프레임 드랍 원천 봉쇄
3. **정밀 타격 시스템 (6단 히트박스)**
   - CharacterController의 물리 이동 간섭과 총알의 타격 판정을 레이어 단위(`Hitbox`, `Projectile`)로 정리함
   - 머리(구), 몸통 및 팔다리 4개(캡슐) 콜라이더로 6등분 히트박스 구축
   - 부위별 데미지 다중 적용 (헤드샷 20딜, 그 외 10딜)
4. **리얼 페인트 칠하기 (UV 맵)**
   - 총알 충돌 시 RenderTexture를 활용해 캐릭터 스킨 어디에나 물감을 덧칠하는 시스템 구현
   - SkinnedMeshRenderer 대응 (BakeMesh로 동적 UV 좌표 추출)
   - 탄약/체력 상태 실시간 UI 표시 패턴 구성
5. **바닥 페인트 데칼**
   - 총알이 바닥에 맞으면 5초 후 자동 소멸하는 페인트 자국 생성
